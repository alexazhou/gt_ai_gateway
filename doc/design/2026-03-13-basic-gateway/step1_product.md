# V1.0: 基础网关能力 - 产品文档

## 目标

打通「客户端 → 网关 → 上游 LLM」的最简链路，提供 OpenAI / Anthropic 协议的转发能力，并建立用户、供应商、模型的核心管理后台，让网关可以作为独立服务运行和部署。

## 功能特性

- **LLM 网关端点**：提供 OpenAI Chat Completions 格式的转发端点，支持流式（SSE）与非流式请求
- **SSE 流式转发**：服务端 SSE、请求 SSE、流式响应中继、失败消息转发
- **供应商管理**：管理多个 AI 供应商（OpenAI、Anthropic、阿里云、DeepSeek 等），每个供应商支持多 URL 与默认 URL 预设，配置 API 格式类型
- **模型管理**：维护对外暴露的模型，绑定供应商，支持启用 / 禁用
- **用户管理**：创建 / 管理用户 Token，用户类型区分（normal / admin / root）
- **请求记录**：记录用户请求与响应，支持查询最新记录
- **鉴权**：管理后台 API 鉴权、ROOT Token 功能
- **双运行模式**：本地 Node 模式 + Cloudflare Workers 模式，两套测试覆盖
- **管理前端**：仪表盘、用户 / 供应商 / 模型管理界面
- **部署**：Docker 镜像支持、CI 测试流程

## 前端功能模块

- **登录认证**：Token 输入登录，验证后进入管理后台，登录状态持久化
- **用户管理**：用户列表（Token 部分隐藏）、新建 / 编辑用户、用户详情（可复制完整 Token）、按类型筛选与按用户名搜索、分页
- **供应商管理**：供应商列表、新建 / 编辑（类型 / 名称 / Token / URL 配置）、详情查看、按类型与格式筛选
- **模型管理**：模型列表、新建 / 编辑（选择供应商 + 模型名称 + 启用状态）、详情查看
- **仪表盘**：系统状态、统计卡片、最近请求列表

## 开发任务概述

V1.0 前端开发按 15 个阶段推进（共约 42 项任务）：

1. 项目初始化与基础配置（Vite + Vue3 + TS 脚手架、依赖、目录结构）
2. 类型定义（通用 / 用户 / 供应商 / 模型）
3. 工具函数与配置（Axios 封装、表单验证、格式化）
4. API 模块（system / user / vendor / model）
5. 状态管理（Pinia auth / app store）
6. 组合式函数（useTable / useAuth）
7. 公共组件（TokenDisplay / StatusCard）
8. 路由配置与守卫
9. 登录页面
10. 布局组件（AppLayout / AppHeader / AppSidebar）
11. 用户管理功能
12. 供应商管理功能
13. 模型管理功能
14. 仪表盘
15. 集成与测试

后端基础能力（LLM 转发、供应商 / 模型管理 API、鉴权、请求记录）与前端并行推进，最终前后端整合部署。

## 产品边界

### V1.0 包含

- 基础 LLM 转发与流式中继
- 用户 / 供应商 / 模型的核心管理
- 本地与 Worker 双模式运行

### V1.0 不包含

- 自动协议转换（后续版本）
- 计费与余额管理（后续版本）
- 流式响应记录的持久化分析（后续版本）

## 验收标准

- [ ] 可通过 OpenAI 格式调用 LLM，流式与非流式均正常
- [ ] 供应商、模型、用户可增删改查，Token 鉴权生效
- [ ] 请求能被记录并查询
- [ ] Node 模式与 Worker 模式均能通过测试用例
