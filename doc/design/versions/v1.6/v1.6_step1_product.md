# V1.6: Windows 跨平台支持 - 产品文档

## 目标

将桌面应用从 macOS 扩展到 Windows，补齐跨平台的构建、启动与进程生命周期处理。

## 功能特性

- **Windows 构建**：新增 Windows 平台 CI 构建支持，产出便携 zip 包
- **跨平台重构**：后端启动逻辑抽取到 sys 模块，统一各平台的进程生命周期管理（stdin pipes、post_spawn）
- **桌面体验**：自动登录、splash 启动流程、隐藏原生标题栏、release 构建隐藏 CMD 窗口
- **兼容修复**：`tauri://localhost` CORS 白名单、WebView2 异步开窗避免死锁、开发工具按 release 禁用

## 验收标准

- [ ] Windows 下 CI 能构建出可运行的桌面安装包
- [ ] Windows 桌面应用启动后端、自动登录、正常使用
- [ ] 关闭主窗口后后端进程正常退出
