# V1.4: 计费管理与 Responses API - 产品文档

## 目标

引入商业化运营能力（用户余额与模型计费），同时扩展 OpenAI Responses API 协议支持，并优化记录查询与仪表盘性能。

## 功能特性

- **用户余额管理**：用户表增加余额，支持充值 / 扣减操作，余额调整会写入充值记录
- **模型价格配置**：为模型配置输入 / 输出（及缓存读取）Token 价格，价格存储在模型对象中
- **充值记录**：查询余额调整记录，支持筛选与分页
- **欠费拦截**：用户余额不足时拦截 API 请求并返回明确错误（此策略在 V1.8 演进为允许透支 + 请求前预检）
- **OpenAI Responses API**：新增 Responses 协议支持与流式累加器，重排协议文档
- **记录查询增强**：记录列表支持按用户 / 模型多选过滤
- **推理模型响应**：支持 OpenAI reasoning_content 字段
- **性能**：仪表盘统计查询优化、record 表新增 created_at 索引、避免全表扫描
- **工程化**：Docker 多平台构建、运行模式命名统一（cloud → worker、local → node）

## 计费 API 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/model/list.json` | 模型列表（含价格） |
| PUT | `/model/:id` | 更新模型（包含价格配置） |
| GET | `/user/list.json` | 用户列表（含余额） |
| POST | `/user/:id/balance/adjust.json` | 调整用户余额（充值 / 扣减） |
| GET | `/balance/recharge/list.json` | 充值记录列表（按用户名 / 时间筛选，分页） |

## 前端功能模块

- **余额管理页面**：左侧导航切换「余额管理 / 充值记录」两个 Tab
  - **余额管理 Tab**：用户列表含余额列，每行提供充值 / 扣减按钮；调整对话框含用户名（只读）、当前余额（只读）、调整类型（充值 / 扣减）、金额、备注
  - **充值记录 Tab**：用户名 / 金额 / 备注 / 操作时间，支持按用户名搜索与时间范围筛选
- **模型价格配置**：模型列表新增价格列，编辑对话框中配置输入 / 输出 Token 价格

## 验收标准

- [ ] 管理员可调整用户余额，充值记录可查询
- [ ] 模型可配置价格，请求后按 token 计费并扣减余额
- [ ] Responses API 格式请求可正常转发与流式返回
- [ ] 记录列表按用户 / 模型过滤有效
- [ ] 仪表盘统计在数据量大时仍响应正常
