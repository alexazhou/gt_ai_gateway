# V1.7: 客户端配置管理与插件 - 产品文档

## 目标

让用户在桌面 / 网页中直接配置 Claude Code、Codex 等客户端，一键生成并写入本地客户端配置；同时引入请求改写插件体系，并打通 Cloudflare 一键部署。

## 功能特性

- **客户端配置管理**：管理 Claude Code / Codex 等客户端的连接配置，支持备份、启用、同步、从本地导入、写入本地配置文件
- **连接模式**：三种模式
  - **GATEWAY（网关模式）**：通过网关用户 Token 走网关转发
  - **VENDOR（供应商模式）**：直连供应商，由网关匹配供应商 ID
  - **OFFICIAL（官方模式）**：直接使用用户自带 API Key，绕过网关
- **配置解析与改写**：config adapter 体系，解析 / patch / 校验客户端配置文件（如 `.claude/settings.json`、Codex `auth.json`），应用备份时 patch 而非整体覆盖，保留用户手动添加的配置段
- **请求改写插件**：内置静态插件——CCH 改写、Responses API Prompt Cache Key 注入、Claude Code 追踪标记移除（详见技术文档；早期「JS 脚本插件」设想未落地，设计记录见技术文档附录）
- **供应商匹配**：后端实现按 URL 匹配供应商，替代前端反查
- **请求记录增强**：持久化 vendor model 映射、vendor test 展示实际请求详情
- **部署**：Cloudflare 一键部署（GitHub Actions）
- **稳定性**：数据库 schema 自动校验、LLM API 错误响应全局标准化

## 验收标准

- [ ] 可为 Claude Code / Codex 生成并写入本地配置文件，应用后客户端可正常连接
- [ ] 三种连接模式均可配置并生效
- [ ] 请求改写插件开关生效且不影响正常转发
- [ ] 通过 GitHub Actions 可部署到 Cloudflare
