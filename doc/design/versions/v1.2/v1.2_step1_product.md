# V1.2: 前端完善与连通性测试 - 产品文档

## 目标

完善管理前端体验，并新增「供应商连通性测试」能力，帮助管理员快速验证上游供应商是否可用。

## 功能特性

- **错误处理统一**：抽取 customError，统一业务异常处理与前端错误提示
- **前端完善**：请求记录表格组件抽取、批量获取关联名称填充、仪表盘最近请求
- **供应商连通性测试**：后端提供 vendor test 端点，前端提供测试 UI，可对指定供应商发送 ping 请求并查看结果
- **系统信息**：侧边栏显示系统版本
- **Root 用户**：支持 root 类型用户，可透传 AI 请求

## 验收标准

- [ ] 可对供应商发起连通性测试，返回成功 / 失败及耗时
- [ ] 前端请求记录展示用户 / 模型名称
- [ ] 错误提示统一展示，不出现裸异常
